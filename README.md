# Ma Galerie Cloudinary

## Présentation du projet
Ce projet web consiste en une galerie de photos simple réalisée dans le cadre du cours de Cloud Computing. Il met en valeur l'utilisation d'un service cloud pour stocker des images.

## Technologies utilisées
* HTML5 / CSS3
* Cloudinary (Hébergement des images)
* GitHub & GitHub Pages (Versionnage et déploiement)

## Utilisation de Cloudinary
Les images ne sont pas stockées localement dans le code source du projet. Elles sont hébergées de manière sécurisée sur la plateforme Cloudinary et affichées sur le site via leurs URL publiques directes.

## Instructions pour exécuter le projet localement
1. Clonez ce dépôt ou téléchargez le code source sous forme de fichier ZIP.
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne.
